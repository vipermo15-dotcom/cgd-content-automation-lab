# 🚀 AI 콘텐츠 & 숏폼 자동화 에이전트 실습 키트 (Dual-Track)

> **"디자인 전공생의 60%가 AI 결제 카드 등록에서 멈추고, 비전공생은 터미널 창에서 좌절합니다."**  
> 직업교육 및 디자인 교육 현장에서 겪은 실제 고민을 바탕으로 구축한 **완전 무료(0원) 보장형 2트랙 AI 실습 키트**입니다.

---

## 📌 왜 이 프로젝트를 만들었는가? (배경 및 고민)

디자인 실무 교육 현장에서 AI 파이프라인 교육을 시도할 때 항상 부딪히는 3가지 장벽이 있었습니다:
1. **유·무료 결제 장벽**: 유료 모델(Gemini Plus, ChatGPT Plus) 결제가 필수가 되면 과반수의 학생이 10분 만에 이탈합니다.
2. **코딩 및 터미널 기피**: 파이썬 환경 설정과 터미널 명령어 입력에서 비전공생들이 큰 심리적 부담을 느낍니다.
3. **진로 목적의 편차**: 에이전시 취업을 원하는 학생과 1인 창업/스마트스토어를 준비하는 학생의 니즈가 완전히 다릅니다.

본 저장소는 이 3가지 문제를 해결하기 위해 **Gemini Plus + DALL-E 3 + 옴니플래시 숏폼**을 결합하고, **결제 없이 0원으로도 100% 완주 가능한 2트랙 파이프라인**을 제공합니다.

---

## 🛠️ 핵심 특징 (Key Highlights)

* **완전 무료(0원) 안전 모드**: API 키가 없어도 번들링된 고화질 에셋과 브라우저 음성(TTS)으로 전 과정 100% 실습 가능
* **마우스 원클릭 구동 (No-Terminal)**: 맥/윈도우 더블클릭 런처 제공으로 터미널 명령어 입력 0회
* **2개 맞춤형 독립 트랙**:
  * 💼 **트랙 A (취업용)**: 디자인 에이전시 및 인하우스 포트폴리오 (디자인 시스템, LinkedIn 전문 아티클)
  * 🌿 **트랙 B (창업용)**: 1인 브랜드 및 스마트스토어 홍보 (성수 팝업 0~3초 후킹 숏폼, 네이버 블로그 스마트 서식)
* **인터랙티브 검토 대시보드**: 30초 숏폼 릴스 플레이어 + 5장 카드뉴스 뷰어 + 원클릭 서식 복사기 내장

## 🚀 빠른 시작 (Quick Start)

### 1. 다운로드 및 실행
1. 본 저장소를 클론하거나 ZIP 파일로 다운로드합니다.
2. 본인의 진로에 맞는 트랙 폴더로 이동합니다.
3. 실행 파일을 **마우스로 더블클릭**합니다:
   * **Mac**: `실습실행_Mac_트랙A.command` (또는 트랙B)
   * **Windows**: `실습실행_Windows_트랙A.bat` (또는 트랙B)
4. 브라우저에서 검토 대시보드가 열리면 카드뉴스와 숏폼 영상을 확인합니다.
